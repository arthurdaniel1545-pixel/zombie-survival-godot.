ZOMBIE SURVIVAL — GODOT 4

Jogo 3D de sobrevivência em um apocalipse zumbi.

Direção visual

- Low-poly moderno e estilizado.
- Não usar visual PS1, PSX ou pixel art.
- Otimizado para celulares Android modestos.
- Priorizar assets gratuitos.

Mundo do jogo

Cidades — exatamente 3

1. Centro urbano.
2. Bairro residencial.
3. Zona industrial.

Florestas — 3 variedades

1. Floresta verde densa.
2. Floresta morta.
3. Floresta escura.

Áreas rurais — 3 variedades

1. Fazenda.
2. Vila rural.
3. Acampamento.

Áreas militares — 3 variedades

1. Base militar.
2. Posto de controle.
3. Campo de treinamento.

Áreas subterrâneas — 3 variedades

1. Bunker.
2. Laboratório.
3. Metrô.

Áreas de saúde — 3 variedades

1. Hospital.
2. Clínica.
3. Posto médico.

Áreas comerciais — 3 variedades

1. Supermercado.
2. Shopping.
3. Posto de combustível.

Regra obrigatória dos edifícios

- Prédios exploráveis por dentro.
- Interiores com móveis, salas, portas e objetos.
- Não usar somente fachadas vazias.
- Criar colisões e acessos entre os ambientes.

Construção

- Permitir posicionamento livre de peças modulares.
- Permitir construções usando projetos pré-montados.
- Separar cada região em cenas próprias.
- Usar modelos 3D gratuitos com licenças verificadas.

Desempenho

- Priorizar baixo consumo de memória.
- Evitar excesso de objetos simultâneos.
- Preparar para Android.

Regra de desenvolvimento

Não substituir os requisitos sem autorização. Construir e testar cada etapa antes de avançar.
