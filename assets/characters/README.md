# Personagens 3D (Grab3D Character Mixer)

Fonte: https://grab3d.com/tools/character-mixer/
Licença: CC0 1.0 (domínio público) — gratuito, uso comercial permitido, sem atribuição.

Modelos esperados (colocar aqui após exportar do mixer):
- male.glb  -> personagem masculino
- female.glb -> personagem feminino

Exportar com: GLB, incluindo animações Idle, Walk, Run, Wave, Jump.
Esqueleto: 19 ossos (hips, spine, chest, neck, head, ombros, braços, mãos, pernas, pés).
Animações em place (in-place); o código move o personagem.

IMPORTANTE: o mixer exporta o personagem como uma única malha (todas as partes skinadas ao mesmo esqueleto). Isso NÃO é um sistema de roupas intercambiáveis. Peças de roupa separadas compatíveis devem ser obtidas de outra fonte ou modeladas separadamente, skinnadas ao mesmo esqueleto de 19 ossos.
